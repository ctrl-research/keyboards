GEMINI

A split, row-staggered 40% whose halves dock back into a regular 12.75u × 4u forty. The row stagger is the joint: the seam steps between T/Y, G/H, B/N and the spacebars, so the two boards interlock like puzzle pieces.

Every row totals 12.75u with standard stagger (1.25 → 1.5 → 1.75). Rows 1–3 step the seam 0.25u right per row; row 4 steps back to 6.25u at the split spacebars, giving the right half a 0.5u tooth that hooks under row 3 — a built-in mechanical interlock.

Docking mechanism (proposal)

  • Alignment — the stepped seam self-aligns in plan; two press-fit dowel pins on the seam faces handle height.
  • Retention — 4–6 pairs of 5×2 mm neodymium magnets, polarity-keyed so the halves only mate one way.
  • Link — TRRS/JST between halves (short jumper docked, long cable split); stretch goal is pogo pins in the seam so docked mode needs no cable.
  • Controllers — one RP2040-class per half, USB-C on each rear edge, QMK SPLIT_USB_DETECT so either side can be master.
